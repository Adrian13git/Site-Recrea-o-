# Era Uma Vez — Recreação Infantil

Site institucional simples, inspirado em brincalala.com.br e
recreacaobehappy.com.br, usando a paleta de cores da marca.

## O que falta pra ficar pronto

- [ ] Número real do WhatsApp — trocar `55SEUNUMEROAQUI` em `index.html`
      (formato: `55` + DDD + número, só dígitos)
- [ ] Handle real do Instagram — trocar `SEUINSTAGRAMAQUI` em `index.html`
- [ ] Lista real de serviços (seção "Serviços") — hoje tem 4 exemplos genéricos
- [ ] Fotos reais das recreações — jogar em `img/` e trocar os placeholders
      da seção "Recreações"
- [x] Texto real da seção "Sobre" — história da empresa

## Paleta usada

- `#7444e4` / `#7444ec` — cor primária (botões, destaques)
- `#683ba9` — títulos, hover
- `#9c64b4` — acento secundário
- `#94c4c8` — acento suave (galeria)
- `#f8fef4` — fundo

## Como ver o site

Abrir `index.html` direto no navegador (duplo clique) — não precisa de servidor.
